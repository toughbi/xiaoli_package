# Third-Party Notices

## Tencent Cloud Speech Recognition

The optional cloud voice-entry feature calls Tencent Cloud Sentence Recognition
over HTTPS after the user configures their own credentials and opts in.

- API documentation: https://cloud.tencent.com/document/api/1093/35646
- Service terms: https://cloud.tencent.com/document/product/301/1971

No speech-recognition model or Tencent Cloud SDK is bundled with the APK.

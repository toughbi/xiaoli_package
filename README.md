# 日迹账本

一个优先面向 Android 的个人收支 App。除了手动记账，还会在用户授权后自动识别微信、支付宝、银行 App 通知和银行短信，并可选使用 DeepSeek 财务专家模型优先判断通知。

## Android App

可直接安装的测试包：

```text
daytrace-ledger-android.apk
```

安装后打开首页的「去授权」：

1. 开启「通知使用权」，并在系统页面允许「日迹账本」读取通知。
2. 返回 App，点击「开启短信」并允许接收银行短信。
3. 保持微信、支付宝和银行 App 的交易通知开启。

首次启动会自动显示权限引导，可分别前往开启通知使用权和短信权限；也可以选择稍后设置。

自动识别从授权之后开始，不会读取授权前的历史通知。历史账单可以通过「数据管理 → 导入备份」导入 CSV。

### 语音记账

按住底部中央的麦克风按钮开始说话，松开按钮结束识别，可以直接说出多笔收支，例如：

```text
今天午餐32元，打车18元，收到工资8000元
```

系统会先展示识别文字、金额、收支方向和分类，确认后才写入账本。中文数字、今天/昨天/前天等日期也支持识别；无法确认时可以使用「手动调整」。

语音识别使用腾讯云「一句话识别」。先打开「数据管理 → 配置腾讯云」，填写 SecretId、SecretKey、确认录音隐私说明并启用。首次授权麦克风后再次按住按钮即可开始。App 不再下载或加载离线语音模型；松开按钮后才将本次录音上传识别，按住期间只维持一个录音会话。

腾讯云凭据使用 Android Keystore 加密保存在本机。当前版本面向个人设备直接调用腾讯云接口；正式公开分发前应改为由自有服务端保管密钥并中转请求。

如果支付宝交易没有自动出现，打开「我 → 查看最近通知诊断」：

- 诊断会记录监听服务收到的所有 App 通知，最多保留最近 500 条。
- 每条记录会列出判断依据、执行操作和最终结果，可区分明显广告、无数字、等待 AI、AI 重试和超时。
- 显示“还没有收到任何通知”：检查系统通知使用权和监听服务连接状态。
- 显示“通知中没有金额”：支付宝这次没有发布可读取金额的交易通知。
- 显示“已识别”但明细没有更新：重新打开 App，或安装最新版 1.16.2。

### 自动识别范围

- 不限来源包名；所有通过本地初筛的通知都会交给 AI 判断
- 本地初筛只排除明显广告和正文完全不含数字的通知；标题不参与数字判断
- 包含金额和明确收支方向的银行短信
- PayPal 等会显示金额的第三方支付通知
- AI 判断收入/支出、支付渠道和常见消费分类
- 同来源短时间重复通知，以及银行通知与短信双提醒自动去重
- 本机通知诊断，可区分“未收到通知”和“收到但未识别”
- 通知图标指纹与应用图标相似度仅用于诊断展示，不参与来源筛选
- DeepSeek 财务专家是自动生成账目的唯一判断来源，支持官方模型列表和模型选择
- 底部中央云语音记账，可一次识别多笔，并在确认后导入
- 自动记录优先显示发送通知的应用图标；微信和支付宝使用主题定制图标，无来源包名时回退分类图标

### 识别策略

- **初步筛选**：通知先在本机检查明显广告关键词和正文是否包含数字。明显广告或正文完全不含数字的内容直接排除，不调用模型；标题只作为 AI 上下文。
- **不按包名筛选**：应用名称、包名和图标只用于诊断展示，不决定通知是否进入 AI。
- **AI 唯一判断**：通过初筛的通知全部进入持久化 AI 队列，由最多 3 个工人处理。只有 AI 返回已完成的真实交易并通过金额校验后，才生成自动账目。
- **失败处理**：AI 未配置、网络失败或单次处理超过 5 分钟时不会使用本地规则生成账目；通知会保留并自动重试。
- **模型隐私**：AI 默认关闭。未启用时自动记账暂停，不会降级为本地记账。启用后，通过初筛的通知应用名、包名、标题和正文会通过 HTTPS 发送到所选模型服务。
- **腾讯云隐私**：云语音默认关闭；只有用户保存腾讯云凭据、确认录音说明并启用后，松开按钮的本次录音才会通过 HTTPS 上传。

支付通知和短信文本格式会随版本变化，自动识别不能保证 100% 准确。识别错误的记录可以编辑或删除；关闭了通知的交易不会被读取。

### AI 财务专家

打开「我 → 配置 DeepSeek」：

1. 填写从 DeepSeek 开放平台申请的 API Key。
2. 保存后点击“刷新可用模型”，从官方 `/models` 接口获取当前账户可用模型。
3. 从下拉列表选择 `deepseek-chat`、`deepseek-reasoner` 或接口返回的其他模型。
4. 选择“AI 必须判断后才生成账目”。
5. 勾选隐私确认并启用，然后点击“测试连接”。

模型返回结构化 JSON，系统还会校验模型给出的金额是否真实出现在通知原文中，防止模型编造金额。API Key 使用 Android Keystore 加密保存。

抽奖、限时活动、参保、推广和最高可得金额等广告信息会被明确排除。模型若把广告误判成交易，也会触发重新校验。

模型可用性、免费额度、费用和速率限制由 DeepSeek 账户决定，可能随时间变化。本项目不捆绑任何 API Key。

### 隐私

- AI 与云语音都有独立开关；只关闭 AI 时，通知分析不会发起网络请求。
- 启用 AI 后，通过初筛的通知应用名称、包名、标题和正文会发送给模型；正文完全无数字或明显广告的通知不会发送。不会发送历史账目。API Key 仅用于服务商鉴权。
- 启用 AI 时会隐藏常见银行卡号和手机号，但仍应只选择你信任的模型服务商。
- 通知诊断会在本机保存最近 500 条 App 通知原文，短信和账目也只保存在手机中；只有通过“非明显广告且正文包含数字”初筛的通知会发送给已启用的 AI 服务。
- 云语音启用后，松开按钮时的本次录音会发送到腾讯云进行转写；不会上传历史账目或其他录音。
- 权限可随时在 Android 系统设置中关闭。
- 当前 APK 使用项目正式证书签名，可覆盖更新；发布密钥需要长期安全保存。

## 项目结构

- `android-app/`：Android 原生项目，包含通知监听、短信解析、去重和 WebView 界面。
- `index.html`、`styles.css`、`app.js`：共享的账本界面和业务逻辑。
- `android-app/tools/TransactionParserSelfTest.java`：支付通知与银行短信解析测试。

## 构建

使用 Android Studio 打开 `android-app/` 即可构建和调试。

本项目也自带 VSCode 命令行构建环境。直接在项目根目录运行：

```powershell
.\build-android.ps1 -Tasks :app:assembleDebug
```

在 VSCode 中按 `Ctrl+Shift+B` 也可以执行默认的“Android: Build Debug APK”任务。

VSCode 新终端会从项目内的 `.vscode/settings.json` 自动加载 JDK、Android SDK 和 Gradle 环境。
如果当前已经有终端打开，关闭终端后重新新建一个终端即可生效。也可以手动执行：

```powershell
$env:JAVA_HOME='E:\code\xiaoli_package\.android-build\jdk\jdk-17.0.2'
$env:ANDROID_HOME='E:\code\xiaoli_package\.android-build\sdk'
$env:ANDROID_SDK_ROOT=$env:ANDROID_HOME
$env:Path="$env:JAVA_HOME\bin;$env:Path"
java -version
```

命令行构建需要 JDK 17、Android SDK 35 和 Gradle 8.14.2：

```powershell
$env:JAVA_HOME = "<JDK17路径>"
$env:ANDROID_HOME = "<Android SDK路径>"
cd android-app
gradle :app:assembleDebug
```

原始网页版仍可通过任意静态文件服务器运行：

```powershell
python -m http.server 8080
```

打开 `http://localhost:8080` 即可使用不带 Android 自动识别的网页版本。
